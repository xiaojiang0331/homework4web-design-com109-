LENS & LEGACY — VERSION 1

OPEN THE WEBSITE
Extract the complete folder, then double-click index.html in a current version
of Chrome, Edge or Firefox. Keep the css, js and images folders beside the HTML
files. No installation, build step or internet connection is needed for the
website itself. External collection links require an internet connection.

PAGES
index.html          Home and featured photographers
photographers.html  Six profiles with expandable stories
gallery.html        Category filters and a full-image viewer
quiz.html           Six questions, feedback and optional saved score
contact.html        Input validation and a local message preview

TECHNOLOGY
HTML5, CSS, JavaScript and jQuery 3.7.1. The jQuery file is included locally
and retains its original licence notice. There are no other JavaScript
libraries, frameworks, package installations or server-side components.

FILES
css/styles.css      Shared styling and responsive layouts
js/script.js        Photo records, quiz answers and page interactions
js/jquery-3.7.1.min.js  Third-party jQuery library; do not edit
images/             Six historical photographs and an original SVG favicon

INTERACTIONS
Photographers: choose Read the story to expand or collapse extra information.
Gallery: choose a category and open a photograph. Previous/Next and the left/
right arrow keys browse the filtered selection. Escape or Close exits.
Quiz: answer every question before checking. Saving is optional and uses only
this browser. Clear saved score removes the stored result. Storage settings
and file:// handling vary by browser; the quiz works without saving.
Contact: complete all fields and the demonstration acknowledgement. Successful
input appears as a safe text preview. No email is sent and no contact details
are stored. Edit my message returns to the form.

IMAGE CREDITS
The Gallery page contains the author, title, date, collection link and rights
record for each photograph. Downloaded images have been resized for the site.
Grid thumbnails and the background use cropped views; the viewer displays
each complete supplied image. The favicon and interface design are original.
